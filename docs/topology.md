# 代理组拓扑

本页描述 `clash-rule*.ini` 中 `custom_proxy_group` 的现行设计：节点命名所表达的角色、组的分层与质量语义、以及各类组的探测频率。

## 节点角色词典

机队节点名中的标记对应「线路 + 落地」的组合方式。命名刻意使用中立词（过境 / 北场），不暴露自建身份。

| 标记 | 角色 | 探测策略 |
|---|---|---|
| 北场D / 北场IX / 北场专线 / 北场过境 / 北转 / F北转 / N转直 | 自建「线路+落地」完整组合节点（可直连，也可当前置）| 过境北场池 fallback@300（自建贵重）|
| 转直（带 NNN 的高质组合）| 高质量组合节点 | 高质灾备 fallback@600，顺序 = 订阅顺序 |
| 北场L / XX-L（US-L、SG-L…）| 纯落地（IP 质量高、线路差），概念上只作落地 | 正常进普通灾备 / 低延池参与探测；下游客户端覆写为其添加 dialer-proxy（前置 = 过境北场地区组）|
| LNIX | 链式组件（LN = 线路，IX = 落地），组合使用 | 零探测（保留正则占位）|
| \|L\| / [LS] / LFB | 量大管饱但 IP 质量差 | 大流量池 |
| LF / 良心 / 吹雪 / 阿拉丁 / YM / 蛋挞 / Kitty / 大流量 / 低倍 / 公益 / 直连 | 商业大流量（0.1x / IEPL / 送中标记）| 大流量灾备 fallback@900；普通灾备 / 低延默认排除（倍率排除词）|
| NNN | 保留给其他应用 | 普通池排除；高质组合（转直…NNN）按订阅顺序进高质灾备 |
| 高质 / 家宽 / 留子 / HOME | 高质量落地 | 高质灾备 / 高质节点 |
| 回家 / gohome | 家内组网穿透 | 30s 灾备 + 600s 低延 |
| WHS / WHSpecial | WH 设备穿透 | 30s 灾备 |
| CQGAS | 内网服务 | select |
| 送中 | 出口被路由到中国 | 大流量池内保留 |

## 组的分层

以 `clash-rule.ini` 为例（89 个组，其中 29 个自动组）：

- **入口 select 组**：`🚀 主要代理`（默认落地点）、`🦽 手动切换`（正则手选）、`🐟 漏网之鱼`。各国 `节点` / `手选` 组用于挑具体节点；`低价区` 为低倍率手选。
- **地区 fallback 组**：`🇺🇸 美国灾备` 等按地区，interval 600；`🔅 大流量灾备` 900；`💖 美国高质灾备` 600。fallback 成员顺序即质量顺序（订阅顺序表达）。
- **过境链**：`<地区>过境` = fallback[`<地区>过境北场`（自建）→ 通用过境北场 → `<地区>过境低延`（商业兜底）]。`过境北场` 300、`过境低延` 为 url-test。
- **穿透组**：`🏡 回家节点` / `🏘 回家专用*`（30s 灾备 + 600s 低延）、`🧭 WHSpecial` / `🌭 WHS*`（30s）。
- **应用分流组**：`📢 谷歌服务`、`Ⓜ️ 微软服务`、`🎵 Spotify`、各国 `应用` 等，多为 select，指向地区组或主要代理。

`general` 变体（81 组，30 自动）用 `🇺🇸 美国低延` 等 url-test@100 取代 main 的部分高质组；`gocn`（32 组，8 自动）围绕回国 / 美国池，含 `🏯 回国低延`、`🐉 回国灾备`。

## 质量与语义

- 选择逻辑：**质量等级优先 > 同质量内延迟优先**；fallback 刻意保留，不机械换成 url-test。
- 高质组 = 一个大 fallback，成员顺序 = 订阅内顺序（高质 > 自建 > 普通），由订阅顺序维护。
- 过境链 = 自建优先（过境北场）→ 商业兜底（过境低延）；过境 / 北场为反审计中性词，不得改名暴露自建。
- 自建与商业的边界：**地区灾备收自建完整节点**（北场D / N转直 等可直连双角色，本身就是完整线路+落地）；灾备只排除**纯过境**（北场过境）与**链组件**（LNIX）。过境低延等商业池全面排除自建。
- `🦔 微软公共` / `🤠 美国公共` 默认走商业过境低延（防 bing 上报导致自建落地送中）。
- `🚀 主要代理` 的成员顺序以各国 `节点` 组开头、`🦽 手动切换` 收尾于 `🚄 本地直连` 之前，缺省即落到首个地区组。

> 落地节点（北场L / XX-L）**不**从自动池排除：它们照常出现在各国灾备 / 低延池中，靠下游客户端覆写的 dialer-proxy 走自建前置。若下游覆写未生效，落地会被直连使用（线路差），属下游配置责任。
