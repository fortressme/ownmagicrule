- 组名、组数量、组类型、嵌套关系全部不变；业务规则目标名不动；主 UI 入口（主要代理/手动切换/各国节点/低延简选/回家/WHS/CQGAS）不动。
- fallback 质量语义不动；手选/自动分离不动；订阅顺序即质量顺序的机制不动。
